# zq8: Q8 lattice gauge theory, first SU(2)-subgroup milestone

Track A of the SU(2) programme (Q8 → 2T → 2O → 2I). Q8, the quaternion group generated by the 2×2
Gaussian-integer matrices i = diag(i, −i) and j = [[0, 1], [−1, 0]], on the open 2×4 ladder of the S3
packages: group and character checks, electric spectrum, Gauss law, exact strong-coupling series of the
1×1, 1×2 and 1×3 Wilson loops in two independent bases, and exact integer-arithmetic certificates of their
finite-coupling values on that fixed lattice. Every
computation is a job of the HEB-C HTTP-0 server (`hebc_ym_http0 serve`). Predictions were frozen in
`PREREG.md` (`4f9fba94…`) before any Q8 code; `ADDENDUM.md` (`f292f206…`, sealed before any code) lowered
J_E so the r = 1 brackets fit the backend's 64-bit spec fields. Rust 1.81, clippy `-D warnings`, integer
arithmetic only, json=0.

Hamiltonian: H/J_E = E + r Σ_p (2 − χ_f(U_p)), electric operator E = Σ_links Σ_{g∈S} (1 − L_g) with
S = {±i, ±j, ±k}; link energies 0 (trivial), 6 (fundamental), 8 (each nontrivial 1-dimensional irrep).
Observable W = χ_f(U_C); W/2 is the (1/N) Re Tr normalisation.

Vacuum energy: E₀ = 6r − r²/8 − 575r⁴/1824768 + O(r⁶). Every coefficient with the wrong parity vanishes,
beyond the registered c_{A,A+1} = 0: the centre {±1} of Q8 flips every plaquette when the free links are
multiplied by central signs, which maps H(r) to H(−r) + 4rN_p. The leading coefficients are exactly
2^−A times the S3 values (1/6, 7/432, 11/6912), because at leading order only fundamental links with
trivial fusions occur and the fundamental link energy is 6 against S3's 3. Normalised (W/2): 1/24, 7/3456,
11/110592.

### W4, the registered FAIL

W4 asks that |⟨W⟩/(c_{A,A} r^A) − 1| be smaller at r = 1/27 than at r = 1/9. For the 1×3 loop the certified
value at r = 1/27 is only 1.0 × 10⁻⁸, so its ratio interval is [0.971, 1.035]; at r = 1/9 the interval
[0.99929, 1.00132] contains 1, so its minimum distance from 1 is 0 and no interval can be closer. The exact
series puts the true deviations at about 2 × 10⁻⁵ (r = 1/27) and 2 × 10⁻⁴ (r = 1/9), both far below the
certified widths: the 1×3 convergence test is beyond this package's resolution. The centre symmetry removes
the r^{A+1} term that made the same test decidable for S3. 1×1 and 1×2 pass W4.

## How it is computed

- `fgroup` (new crate in `native/ym/crates`): finite-group data (S3 as in `torusl`, Q8 from exact
  Gaussian-integer matrix products), the open-strip builder `fgconf` (byte-identical to `ymconf` for S3),
  `fgcheck` (G1–G3), and `fgwser`, the series solver: method A eliminates exactly in the gauge-orbit basis;
  method B works in the full gauge-fixed configuration basis and inverts the electric operator with the
  polynomial over all 37 possible nonzero electric eigenvalues, checking every solve exactly.
- Certified values by concavity of E₀ in a loop source λ = 10⁻⁸: (L₊ − U₀)/λ ≤ ⟨W⟩ ≤ (U₀ − L₋)/λ, each energy
  bracketed by `sturmrs` to one threshold unit (9.3 × 10⁻¹⁹ J_E), the final brackets re-executed by `verify`.
- New backend job kinds `fgcheck`, `fgwilsonmat`, `fgwilsoncount`, `fgwilsonseries`; 1129 counts.

## Replay and integrity chain

`run.sh` checks both seals, builds the native/ym workspace and the driver with Rust 1.81, runs clippy,
starts `hebc_ym_http0 serve` on a fresh ROOT, runs everything through it and checks byte identity with
`RESULT.hbp`; `results-replay.yml` runs it on the exact head. `SHA256SUMS` covers every other file,
`ZQ8.hbi` holds the chained `EMIT` rows (`pid[0] = sha16("EMITTER-SEED|SUN-ZQ8-2026-10-30-CLOUD")`,
`pid[n] = sha16(pid[n-1]|name)`), and `ZQ8.seal = sha256(SHA256SUMS + ZQ8.hbi)`.
