# What the no-float gate lets stand, each with its reason. A file row states how many findings the gate counts in that file, so one more float there fails as well. A path ending in / covers its folder. Anything not listed must hold no floating point.
native/ym/vendor/ | Third-party integer crates pinned by Cargo.lock. Every manifest here sets default-features = false, which compiles out the std float paths in their sqrt, cbrt, nth_root, Display and parse. The floats left in their source are listed function by function in no-float-compiled.yml's output, each read from the compiler's IR as reached by no project crate
